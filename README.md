## 内容

- **基金详情**：点击任意基金行查看净值/超额曲线、风格归因、多周期超额

## 口径说明

- **超额收益 = 基金收益率 − 基准指数收益率**（算术超额）
- 基准为对应**价格指数**（未含股息），基金采用**累计净值**（含分红）
- 例：鹏华沪深300指数增强A（005870）2025 年超额 = 22.13% − 17.66% = **+4.47%**
- 超额回撤 = 累计超额距其峰值的差值；月胜率 = 月内日超额之和 > 0 的月份占比

## 数据来源与更新
